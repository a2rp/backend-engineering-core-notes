# Backend Engineering Core Notes

A focused React study guide for revising practical backend engineering concepts with clear explanations, JavaScript examples, and route-based topic navigation.

![Backend Engineering Core Notes screenshot](screenshot.png)

## Features

- Node.js internals, API design, authentication, security, performance, and observability notes
- Expandable sidebar with dedicated routes for every topic
- Lazy-loaded pages with a loading spinner during navigation
- Light and dark themes with a responsive layout
- Local branding and social preview assets for GitHub Pages

## Tech Stack

- React and Vite
- React Router
- styled-components
- React Icons

## Setup

```bash
npm install
npm run dev
```

Useful checks and deployment commands:

```bash
npm run lint
npm run build
npm run preview
npm run deploy
```
